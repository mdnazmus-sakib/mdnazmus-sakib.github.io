# FIX YOUR PHOTOS — flat upload, no folders

Your site shows alt text instead of photos because **the `photos` folder never made it to GitHub**.
Your repo has only 5 files: `.nojekyll README.md index.html script.js style.css`

GitHub's "Upload files" page **silently ignores folders**. That is why it failed many times.
It looks like it accepted the drag, then uploads nothing from inside the folder.

## Solution: there is no folder any more

This version has **every file at the top level**. No `photos/` subfolder to drag.
Images are referenced as `sakib-letters.jpg`, not `photos/sakib-letters.jpg`.

You upload 43 loose files and it works.

---

## Steps (takes about 2 minutes)

### 1. Get the files
Download **`sakib-UPLOAD.zip`** and **extract it** on your computer.
You will see 43 files all sitting together — no folders.

### 2. Delete the old files from your repo (optional but cleaner)
Skip this if you want. The new files overwrite the old `index.html`, `style.css`, `script.js`.

### 3. Upload
1. Go to `github.com/mdnazmus-sakib/mdnazmus-sakib.github.io`
2. Click **Add file** → **Upload files**
3. Open the extracted folder, press **Ctrl+A** to select all 43 files, drag them in
4. Scroll to the bottom → click **Commit changes**

> **Do not drag a folder.** Drag the *files inside it*. With this version there is no
> folder to drag, so it cannot go wrong.

### 4. Wait, then hard-refresh
GitHub Pages takes 1–2 minutes. Then press **Ctrl + Shift + R**.

## If upload STILL fails

Some browsers and networks choke on 40+ files at once. Try these in order:

**Option A — upload in batches**
Let's say 10 to 15 files at a time. Click *Commit changes* after each batch.
New uploads add to what's there; they don't replace it.

**Option B — GitHub Desktop (most reliable, no folder problems)**

1. Download **GitHub Desktop** from desktop.github.com and sign in.
2. **File → Clone repository** → pick `mdnazmus-sakib.github.io` → choose a local folder.
3. Open that folder on your computer. **Copy all 43 extracted files into it.**
4. GitHub Desktop will list the changes on the left.
5. Type a summary like `add photos` → click **Commit to main** → click **Push origin**.

This always works because it copies real files into the repo instead of relying on a web form.

**Option C — command line**

```bash
git clone https://github.com/mdnazmus-sakib/mdnazmus-sakib.github.io.git
cd mdnazmus-sakib.github.io
# copy all 43 extracted files into this folder, then:
git add .
git commit -m "add photos flat"
git push
```

## About Google Drive

Ignore it. You do not need Drive for this. Drive cannot serve images to a website
reliably — Google blocks hotlinking, and the thumbnail endpoint is rate-limited per file,
so a 20-photo gallery gets throttled and shows broken tiles.

The `USE_DRIVE` setting in `script.js` stays `false`. Keep it that way.
